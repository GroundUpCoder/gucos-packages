# pcre2test

Unpublished source candidate with immutable historical CLI fixtures and PCRE2
sources. Preserves historical --no-native-functions compilation for recursive
regex paths, 8-bit mode, disabled JIT and archived configuration. This is a
self-contained CLI executable; it does not replace the published PCRE2 library.
Tests retain RunTest -8 -nojit and capture/no-match checks.
Guest/binary/installed/reload acceptance pending.
