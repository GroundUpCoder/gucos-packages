# pango

Unpublished historical configured profile, version1.50.14-1. Pinned original
sources and license bytes are retained; install-layout adaptations are separate.
Retained static/shared font consumers are prepared, not executed.
Pango requires the actual host-prepared HarfBuzz package, plus Cairo/Fontconfig/
FreeType/FriBidi and GLib/GObject/list-model dependencies. The retained consumer
checks shaping, layout, Cairo rendering and its CJK font fixture.
