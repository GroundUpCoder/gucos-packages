# GNU m4

Unpublished source candidate from GNU m4 1.4.19, retaining historical configure
flags, generated-file ordering, gnulib strstr selection and documented SIGKILL
stderr expectation. Build runs make with one worker and the upstream checks.
Installs executable, three Info parts, manual and license explicitly. Tests
cover macro expansion, argument reversal, arithmetic and frozen-state reload.
Guest execution and binary/public acceptance remain pending. The known optional
changeword/stack-overflow upstream skips must be recorded from actual logs.
