# XPM and Athena widget libraries

Static libXpm and libXaw7, built in the guest from the preserved prepared X11
source tree. Depends on x11-toolkit; toolkit retains ownership of the headers.
This package owns only its two libraries and license files. It enables JWM's XPM
icons and Athena clients such as xcalc, xmessage and xterm.

provenance.json records exact historical source identities. Functional client
acceptance exercises these libraries; no full upstream library suite is claimed.
