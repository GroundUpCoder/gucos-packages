# JWM application entries

An optional integration package for the accepted2048, Calculator, Text Editor,
Clock and Eyes applications. Owns only five desktop entries and its license;
all existing application payloads and catalog identities stay unchanged. Exact
runtime dependencies include JWM, the desktop-entry launcher, xterm and each app.
2048 runs in an xterm PTY; X applications use the current desktop display.

Original gucos integration metadata, Apache-2.0. A source-only staging check is
not functional acceptance. Real JWM menu launch,2048 gameplay, calculator input,
editor save/reload, application quit/relaunch and browser reload remain required
before publication. Entries have distinct stable gucos-desktop-* identifiers.
