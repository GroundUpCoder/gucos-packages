# x11-toolkit runtime package

Historical source snapshot from wasm-posix-old commit 0b9b3245fe11a3bc677d81113cba90cd0ae80446, apps/x11-apps/source. Sources and licenses preserved in source.tar. Guest-only build; experimental acceptance is recorded separately.
The toolkit recipe selects ICE, SM, Xt, Xmu and Xrandr from the historical build; it does not build xterm or Xft.
