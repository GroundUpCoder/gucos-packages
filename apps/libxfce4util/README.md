# libxfce4util

Unpublished historical4.20.0 utility-library candidate. Archived sources and
configuration are unchanged. Retained consumer verifies public version, strings,
64KiB settings persistence and resource lookup; both static/shared links are
now exercised. Declares pkgconf explicitly with published GIO/libintl closure.
This library does not imply an XFCE desktop migration. Guest and binary/public
acceptance remain pending.
