# Simon Tatham puzzles

Source candidate preserving snapshot20260923.616da16 and its historical GTK3
X11 overlay. Includes40 sgt-prefixed games and their HTML help. Uses the accepted
gtk3-x11 userland package. The upstream no-icon frontend and historical disabled
GTK print dialog are retained; command-line PostScript support remains unchanged.

Package-owned desktop entries expose Fifteen, Mines, Net, Solo, Same Game and
Untangle. The source gate covers version/generation for all40 binaries, Net/Solo
solvers and Fifteen save generation. Real JWM menu launch, legal keyboard moves,
Undo, save/load, quit/relaunch and persistent reload are required before acceptance.
No new build, gameplay or publication is claimed by source preparation.
