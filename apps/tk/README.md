# Tk

Historical8.6.16 X11 profile, retaining124 original compilation units and flags,
static SDK, wish and complete Tcl/Tk script payload (182 outputs).
Wish alias is a same-byte regular file. Depends on exact Tcl8.6.16 and the public
X11 server package. No new private X or Cairo providers are introduced.

Recipe tests establish static linking, Tcl version and basic Tk APIs without
a display. Full historical widget/canvas/PNG/clipboard/keyboard and upstream
pack/grid acceptance remains a separate browser gate before publication. Those
retained sources remain inside source.tar. No fresh guest acceptance claimed.
