# Quake shareware distribution

The package preserves the complete original idstuff quake106.zip unchanged and
all 16 original installer payload files in a gzip tar for local extraction.
Every original payload byte and filename is preserved, including SLICNSE.TXT
and LICINFO.TXT. shareware-inventory.json records exact hashes and sizes.
The ZIP mirror and archive hashes are recorded in source provenance.json.

The data remains proprietary under id Software's shareware terms, separate from
the GPL engine. Distribution is complete, compressed and free of charge; the
original agreement accompanies it. Launching quake extracts the complete payload
into the user's home directory and preserves existing files. No isolated pak is
an active package input or binary output. The old historical pak-only provenance
claim is excluded from the active source archive, with that exclusion recorded.
