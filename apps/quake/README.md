# Quake migration candidate

Retains the pinned historical engine sources; filtered source provenance records
removal of isolated pak0 and its inaccurate redistribution claim. Complete original
shareware distribution and compressed16-file payload are separate immutable inputs.
Both are preserved in package outputs; game launch extracts all data into user
state. Original filenames and bytes are retained, with an id1/pak0.pak compatibility
link created only locally. Existing files, links, saves and deletions are preserved.

Original agreement and complete distribution accompany the separately licensed GPL
engine. See SHAREWARE-PROVENANCE.md and shareware-inventory.json. Fresh source build,
interactive workload, binary/reload and independent publication gates are pending.
