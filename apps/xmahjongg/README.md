# XMahjongg retained translated-C migration

The pinned historical Git source and exact previously generated C are separate
owned archives. The latter was recovered from the independently audited source
cache archive recorded in provenance. It retains 1,060 C artifacts, with 1,059
objects in archive order and constructor 762.o linked separately. Four metadata
and response files complete its 1,064 members. This is not a new host translation
or a claim that the guest compiler accepts upstream C++.

The guest build retains the historical C compilation/link recipe, changing only
its recipe-local source root. X11 SDK/server comes from the accepted x11-server
package. The same thick tiles, default background and layout are installed.
GPL, Click license, upstream tile attributions and the combined notice remain.
The generated provenance is installed byte-for-byte as translation.json.

Staged help is not gameplay acceptance. Fresh binary, real JWM menu launch,
matching/removing tiles, undo/restart, quit/relaunch and browser reload remain
required, followed by independent review and public install/gameplay gates.
